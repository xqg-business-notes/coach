# 小强哥创业教练

Business Coach · 小强哥商业笔记

**把创业和经营中的困惑，变成有依据的判断和下一步行动。**

有技能或粉丝，却不知道怎么变现；有产品，却不知道先找谁购买；面对合伙、招聘、定价或融资，拿不准如何取舍——都可以带着具体问题来聊。

创业教练会结合小强哥持续整理的创业知识与方法，分析你的实际情况，比较选择，给出可以尝试的下一步。行动后带着反馈回来，可以继续调整判断。

## 可以帮你做什么

- 找方向、评估创业点子，确定先验证什么。
- 设计产品与付费服务，讨论定价、变现和客户需求。
- 分析获客、销售与增长问题，安排下一步尝试。
- 梳理合伙、招聘、团队管理及经营中的取舍。

不用先选课程或填问卷，直接说现在的情况即可。例如：

> 我有一项专业技能，也积累了一些粉丝，但还没找到合适的付费产品。我每周只能投入一个晚上，应该先验证什么？

- 查询时会把当前问题的必要简述发送到知识服务，不上传整段聊天。该服务不保存提问原文、方法回复或完整聊天。为了解使用情况与改进服务，会记录经过哈希处理的安装标识、首次及最近访问时间、连接与查询次数、查询成功或失败次数；按日明细保留最近 30 天，安装级记录在连续 30 天未使用后清理。防滥用所需来源标识哈希、计数与方法编号约保留 30 天。你使用的 AI 平台和网络服务商各自的数据规则仍适用，详见[查询与数据说明](skills/xqg-business-coach/references/query.md)。
